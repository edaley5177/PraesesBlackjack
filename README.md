This is all the code needed to run a basic blackjack simulation. 
It will allow the user to simulate and view a full black jack game.
It will keep playing and dealing hands until the deck runs out of cards.
The user will input how many decks in the shoe, and the number of players(user and bots).
Dealer is preprogrammed to play a certain way. Bots will play in a preprogrammed way. User player will follow commands from user
