This is all the code needed to run a basic blackjack simulation. 
It will allow the user to simulate and view a full black jack game.
It will deal one round of hands.
The user will input how many decks in the shoe, and the number of players(all bots).
Dealer is preprogrammed to play a certain way. Bots will play in a preprogrammed way. 
This is a java program. It takes input from the console to determine how many bot players and how many decks to use.
